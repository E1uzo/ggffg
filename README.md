# Форма обратной связи «Связаться с нами»

Веб-форма обратной связи с клиентской валидацией полей, реализованная на чистом HTML, CSS (с эффектом Glassmorphism) и JavaScript (Vanilla JS).

## Функционал и правила валидации

* **Email:** Проверка на корректность ввода электронного адреса с помощью регулярного выражения.
* **Телефон:** Строгая валидация номера. Допускается только формат `+7` и 10 цифр после него (например, `+79991234567`).
* **Загрузка файла:** Ограничение на тип файлов. Форма принимает только изображения с расширением `.jpeg` и `.jpg`.
* **Интерфейс:** Современный адаптивный дизайн с полупрозрачным белым фоном (эффект матового стекла) и градиентным задним планом.

## Структура проекта

* `index.html` — HTML-разметка формы и структуры страницы.
* `style.css` — Стили оформления, адаптивная верстка и градиентный фон.
* `script.js` — Логика валидации данных, перехват отправки и вывод ошибок.

## Запуск проекта

1. Склонируйте репозиторий или скачайте файлы проекта.
2. Откройте файл `index.html` в любом современном браузере.
3. Проект не требует сборщиков или локального сервера, все работает локально.
